我的模拟盘选股看板

确认后，才模拟买卖

初始资金10万元，最多持有3只股票。推荐不会自动买入。

第一次怎么操作

  1. 在企业微信右上角“…”选择在浏览器中打开，用手机浏览器访问本页。
  2. 点下面的按钮。如果看到 Sign in，先登录 1024605643-cell。电脑的登录状态不会同步到手机。
  3. 找到 Run workflow，分支保持 main。展开后填写下表的3项，再点绿色 Run workflow 提交。
登录 GitHub / 提交模拟委托
字段怎么选
操作 side买入、卖出，或撤销待成交委托
股票代码 code填写你决定交易的六位代码
比例 fraction25%、50% 或 100%；买入占可用现金，卖出占当前该股股数

例如：买入 + 你选定的代码 + 50%，表示用一半可用现金提交模拟买入委托。价格由程序获取，无需填写。

提交成功不等于已经成交。以企业微信“模拟成交”回执为准；请勿反复提交。想先熟悉操作，可选“仅检查连接”，代码留空，不会买卖。

仍找不到 Run workflow？

确认已登录上述账号，然后刷新页面。必要时在手机浏览器菜单切换“桌面网站”。“0 workflow runs / This workflow has no runs yet”仅表示尚无运行记录，不是报错。

模拟规则与当前限制

  • 交易时段尝试取得确认后的新行情；休市、旧行情、停牌、涨跌停限制或对手盘不足时等待。委托24小时未成交自动失效，也可选择撤单。
  • 模拟计入佣金万分之2.5（每笔最低5元）、双边过户费、卖出印花税，以及0.1%单边滑点。佣金为暂定值，可能与你券商不同。
  • 当天买入的股份当天不能卖出。科创板最低买入200股，其余以100股为买入单位。
  • −1.25%提醒卖出25%，−2.5%提醒卖出剩余50%，−5%提醒清仓。+3%/+6%分段止盈，之后峰值回撤3%提醒退出；持有满两周提醒退出。均需人工确认。
  • 交易时段约每30分钟检查，GitHub调度可能延迟。−5%是触发阈值，无法保证成交时亏损不超过5%。

这是模拟执行环境，尚未连接券商实盘。一周结果只能作为观察样本。
