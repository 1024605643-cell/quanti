模拟交易改用本机软件

委托直接保存到电脑，后台持续读取行情，无需再点击 GitHub Run workflow。

下载 Windows 64位版

打开软件下载页
  1. 在 Windows 电脑下载 ZIP，完整解压。
  2. 双击 QuantiDesktop.exe，保留旁边的 _internal 文件夹。
  3. 先核对迁入的待成交委托，再点击启动本机监控。不要重复提交已有买单。
  4. 后续在软件里选择股票、操作及比例，点击确认提交；以已成交状态或企业微信成交回执为准。

为什么原来显示 Failure？

相同股票已经有待成交委托，再次提交被拒绝。旧系统还需要等待下一轮云端任务重查行情，本机版改为约每2秒检查。

云端模拟交易已暂停，避免与本机重复执行。此网页和旧云端报告中的账本仅为迁移快照，最新持仓和收益请在 Windows 软件中查看。

使用范围

软件关闭、电脑休眠或监控暂停时不会持续检查。网络异常、停牌、涨跌停或T+1限制仍可能导致等待。
